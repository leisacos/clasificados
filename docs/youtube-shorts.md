# YouTube Shorts queue

Titles and descriptions for uploading Instagram Reels to
[youtube.com/@theplacesnotfaces](https://www.youtube.com/@theplacesnotfaces) as Shorts.
The daily sync adds a block for every new Reel (see `docs/daily-sync.md`, section 7b).

**How to use it**
1. Upload the Reel to YouTube (no Instagram watermark: use the original file).
2. Copy the title and description below.
3. Paste the video ID (the part after `/shorts/` in its URL) into `YouTube ID:`.
   The next daily sync embeds the video in the story.
